# Generated site and design system

This directory contains the public frontend design system, static preview, and accessible component plan for Elecciones 2026.

## Structure

- [`COMPONENT-PLAN.md`](COMPONENT-PLAN.md): Accessible component plan, component state matrix, and mobile wireframes (360, 390, 430 CSS px).
- [`tokens/tokens.json`](tokens/tokens.json): Machine-readable local design tokens schema (WCAG 2.2 AA verified).
- [`tokens/tokens.css`](tokens/tokens.css): Pure CSS custom properties declaring local tokens. Zero external CDN dependencies.
- [`styles.css`](styles.css): Mobile-first stylesheet consuming local tokens.
- [`index.html`](index.html): Accessible HTML prototype demonstrating the four MVP destinations without external CDN dependencies.
