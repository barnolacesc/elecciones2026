# Writing standard

Use English for repository documentation, OpenSpec artifacts, code identifiers, and code comments. Use Spanish for public MVP interface text and reviewed political content. Keep language-specific public text separate from code logic. Plan reviewed Catalan and optional English translations as later work.

Use ASD-STE100 principles in technical documents: short sentences, one instruction per sentence, direct verbs, defined terms, consistent names, and explicit conditions. Avoid idioms, vague qualifiers, and ambiguous pronouns. A formal claim of ASD-STE100 compliance requires a reviewer with the current controlled dictionary and specification. This draft has not received that review. Add that review as a release gate for documentation that must meet the standard strictly.
