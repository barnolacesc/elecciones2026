# Quiz comprehension checks

Roadmap package: E4.3, task 3.5. Change: `programme-alignment-quiz`.

Status: facilitator draft. No participant session or editorial approval is recorded here. Automated browser checks verify displayed values and controls; they do not measure human understanding.

## Setup and recording rules

Run the private mock preview as described in [QUIZ.md](QUIZ.md). Use set `mock-1.0.0`, method `1.0.0`, and a fresh session with normal topic weights. The examples and answers below are fictional assignments. Ask volunteers to use these assignments, without disclosing their own political views. Participation is optional and can stop at any point.

Do not record names, contact details, participant identifiers, political views, answer histories, screen recordings, screenshots of participant sessions, or individual result records. Do not add a feedback form, analytics, or session replay to the quiz. Keep only aggregate attempted/completed/assisted counts by task and brief interface findings without personal information. The operator runs sessions privately; this document sends no invitations.

Use the Spanish prompts below. Read one task at a time. Do not explain the expected answer before the volunteer attempts it. If help is necessary, count that attempt as assisted. Stop an exercise if the volunteer declines; exclude it from the attempted denominator.

Proposed acceptance for editorial review: each critical task must be completed and explained without help by every volunteer who attempts it. An assisted completion or incorrect explanation requires a copy or navigation review and a new test of the changed flow. Agree the volunteer sample and acceptance rule with the editorial owner before treating results as G5 evidence. Counts from a small convenience sample cannot establish general comprehension or accessibility compliance.

## Assigned starting state

Draft instruction: “Esta prueba usa ejemplos ficticios. No respondas según tus ideas políticas. Pulsa «Empezar». Marca «Totalmente de acuerdo» en las preguntas 1 a 8 y pulsa «Siguiente» después de cada una. En la pregunta 9, pulsa «Ver resultado». No hace falta revisar las respuestas antes.”

Facilitator checkpoint: eight numeric answers across four topics, eight skipped items, normal weights. Example A displays 50%; Example B displays 38% (unrounded 37.5%); Example C has no score because its source coverage is incomplete. These are fixture calculations, not political claims.

## Tasks and expected evidence

### 1. Explain an edited answer

Draft prompt: “Cambia solo la pregunta 1 a «Totalmente en desacuerdo» y vuelve al resultado. Busca la explicación del Ejemplo A. Explica qué ha cambiado y cómo afecta al porcentaje.”

Expected evidence: the volunteer can enter optional review, edit question 1, and return directly to results. They open “Por qué aparece este porcentaje”, identify the assigned answer, the example's fictional support position, and 0% agreement on that item. Housing has 0% mean instead of 50%. With four equally weighted answered topics, Example A falls from 50% to 37.5% (38% display), a decrease of 12.5 points. Both questions in each topic count in its mean; skipped topics do not count in the current aggregate.

### 2. Explain a topic weight

Draft prompt: “Da doble peso a Vivienda. Explica qué significa y por qué cambia el resultado. Después, restablece los pesos.”

Expected evidence after task 1: housing represents 40% of the current aggregate, and each other answered topic represents 20%. Example A moves from 37.5% to 30%; Example B moves from 25% to 20%. The same weights apply to both examples. An unanswered topic does not start contributing merely because its weight changes. Restoring weights restores the previous calculations.

### 3. Distinguish neutral from skipped

Draft prompt: “Con los pesos normales, cambia la pregunta 1 a «Ni de acuerdo ni en desacuerdo» y mira el resultado. Después omite esa misma pregunta. Explica la diferencia.”

Expected evidence: neutral remains a numeric answer, with eight answers and four topics. Example A's unrounded percentage is 43.75% (44% display). Skipping removes that answer, leaves seven answers and four topics, and withholds aggregate scores. Neither neutral nor a skip is an inferred party position. The visitor can return and restore the assigned answer.

### 4. Distinguish missing evidence from opposition

Draft prompt: “Vuelve al resultado con ocho respuestas. Busca por qué el Ejemplo C no tiene porcentaje. ¿Qué puedes concluir de esa falta de datos? Abre también las fuentes de una pregunta.”

Expected evidence: the volunteer finds the source gap and explains that it does not mean opposition. They identify that the mock sources are fictional and contain no official political document. Mark real citation inspection as **not evaluated in mock mode**. Do not invent a source link to make this task pass.

Required later repeat: with an approved real set in a private preview and assigned synthetic answers, ask the visitor to locate the official document link, programme version, exact page or section, and review date for one scored position. The facilitator must verify these against the approved editorial record. Task 3.5 stays open until real citation inspection and the other required comprehension checks are complete.

### 5. Explain unanswered-item limits

Reset and repeat the assigned starting state before this task.

Draft prompt: “Busca qué podría pasar si completas las preguntas omitidas. Explica qué significa el intervalo y qué no significa.”

Expected evidence: Example A has possible full-set outcomes from 25% to 75%. The volunteer explains that these are possible calculations for completing all 16 items, not probabilities or statistical confidence. The current percentage uses only answered topics; the full-set limits include all topics. Missing answers can change the relative alignment of the examples. No winner is implied by overlapping limits.

### 6. Recognize scope and voluntary review

Draft prompt: “Explica qué dice este resultado sobre a quién votar. ¿Necesitas revisar todas las respuestas antes de verlo? ¿Qué pasa si borras las respuestas o recargas la página?”

Expected evidence: the volunteer identifies that the quiz compares only the answered measures and gives no voting recommendation. Review is optional. Clearing answers or reloading starts an empty session; no account or answer recovery is offered.
