## Acquisition procedure

1. Confirm the 2026 candidacy and exact coalition name against official electoral publications.
2. Search the candidacy's official website, transparency archive, campaign site linked by that website, and verified official social announcement for a complete general-election programme.
3. Record the landing-page URL, direct document URL, publisher, publication and retrieval dates, election scope, language, version, SHA-256, and later replacements. Preserve the source's original filename. Do not execute embedded content.
4. Mark the source `missing`, `announced`, `partial`, `published-unverified`, `verified`, or `replaced`. Only `verified` sources can support published comparison claims.
5. Review publication and quotation rights before storing or redistributing a copy. Prefer a source link and short reviewed quotation over PDF redistribution.
6. Recheck known official paths at a measured cadence and after an official publication announcement. Record each check; avoid aggressive polling. If a document changes, hash the new version and invalidate affected reviewed claims.

## Readiness implication

The team can build schemas, import tools, mobile UI, and security checks using labelled fictional fixtures. A two-party real-data pilot cannot pass its gate until two 2026 general-election programmes and their rights/review records are available. Cesc does not need to collect PDFs manually yet; official paths already exist for discovery. Manual outreach or additional sourcing is needed only if an official programme is announced but cannot be located or accessed through those paths.

A separate **2023 proof of concept** can use two official 2023 general-election programmes for a private, clearly labelled end-to-end rehearsal after a rights and editorial check. It can exercise import, provenance, comparison, source links, and mobile presentation. Keep an immutable election ID in all records and generated pages. A later 2026 import creates new programme and statement records; it does not relabel 2023 material. The comparison code and schemas should be reusable, while content extraction, review, and some party/coalition mapping must be repeated.
