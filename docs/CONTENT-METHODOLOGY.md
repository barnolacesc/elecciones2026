# Editorial method — draft

- **Comparison unit:** a specific proposal, not a slogan. Separate objective, instrument, conditions, funding, and scope when the source states them.
- **Statement state:** `explicit`, `reviewed_inference`, or `not_found`. An inference needs the passage and review reason. `not_found` is not an opposing position.
- **Agreement:** the same measure or an operational objective with comparable scope. Show differences in amount, date, jurisdiction, and conditions even if headlines match.
- **Source:** official programme URL, version, hash, page or section, and access date. Preserve an old version if a party changes its programme.
- **Coverage:** show received, partial, and missing sources and the data cut-off date. Track all candidacies within the approved inclusion rule.
- **Review:** extraction proposal → source check → neutral text → independent review → publication. Record disagreements and corrections.
- **Transparency:** publish inclusion rules, editor, update date, limitations, correction policy, and dataset versions. An in-site submission route is a separate post-MVP feature.
- **Limit:** the site helps readers. It does not replace programmes, endorse a party, or predict future conduct.

The public version of this method must use reviewed Spanish text. This English file controls project work. A controlled-language review is required before a strict ASD-STE100 compliance claim.
